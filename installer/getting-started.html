CLIPPY SSH

Copy locally.
Paste over SSH.

  1. Open a new PowerShell tab in Windows Terminal.
  2. Connect with your usual command, such as ssh user@server. Clippy prepares the Linux server automatically using your existing SSH authentication.
  3. Copy a screenshot or an Explorer file. Press Ctrl+V in the remote session. Its uploaded path appears at the cursor.

The path stays editable. Clippy never presses Enter. For example, type file , paste an image, then press Enter yourself.

Clippy starts at sign-in. The tray menu lets you pause or exit the background app. Uninstall through Windows Settings → Apps → Clippy SSH.

This preview supports Windows x64, Windows Terminal with PowerShell, Windows OpenSSH, and Linux x86_64/arm64 servers. VS Code, WSL, PuTTY, nested SSH, and containers are not yet supported. Ordinary text paste stays native. Use ssh.exe to bypass Clippy.

If Windows Terminal is missing, install Microsoft's Windows Terminal. OpenSSH Client is available in Windows Settings → Optional features. Managed PowerShell policies may require your administrator's help.
