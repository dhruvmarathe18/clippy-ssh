Download **Clippy-Setup-0.3.1-x64.exe** below and run it. No Rust installation, extraction, or setup command is needed.

After Setup finishes, open a **new PowerShell tab in Windows Terminal**, connect with your usual `ssh` command, copy a screenshot or Explorer file, and press **Ctrl+V**. Clippy uploads it and inserts the remote path without pressing Enter or showing a success popup.

### Included

- Windows client, background app, and embedded Linux x86_64/arm64 helpers.
- Automatic PowerShell integration and sign-in startup for the current user.
- Windows Settings → Apps uninstall entry and getting-started shortcuts.
- Setup preflight, repeat-install support, and configuration rollback if installation fails.
- Default-only PowerShell profile enablement: when no policy is configured, Setup uses `RemoteSigned` for the current user. Existing explicit and organization policies are preserved. Uninstall restores a policy changed by Setup when its value is still unchanged.
- Mouse-report spam fix, background-pipe deadlock fix, and private uploads after `sudo su USER` using existing noninteractive sudo permission.

### Requirements and preview limits

Windows x64, Windows Terminal, Windows OpenSSH Client, PowerShell, and a Linux x86_64 or arm64 SSH server. Windows Terminal and OpenSSH are prerequisites; this installer does not install Windows optional features. No administrator access is required to install Clippy. The remote helper is installed automatically on the first supported connection.

This is a **prerelease**. VS Code terminals, WSL, PuTTY, nested SSH, and containers are not supported yet. Linux arm64 is cross-compiled but has not been tested on arm64 hardware. Sign-in startup, every Windows Terminal layout, and password/MFA configurations still need broader manual testing.

The executable is **unsigned**; Windows may display an unknown-publisher or SmartScreen warning. `SHA256SUMS.txt` lists the release asset hashes. No code-signing certificate is bundled or claimed.

### Validation

Publication is gated by Windows/Linux Rust tests and lint checks, a fresh Windows installer lifecycle test, policy restriction handling, profile loading, repeat installation, startup/IPC verification, rollback from a failed background launch, and uninstall/policy restoration. Live transfer tests additionally cover direct SSH, ProxyJump, tmux, switched-user ownership, cancellation, and target-change protection.

The portable ZIP is optional for developers and users who prefer explicit setup. Most users should download only the installer EXE.
